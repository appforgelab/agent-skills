# Agents

This repository is public. Skills here must be generic and safe to publish:

- No credentials: API keys, tokens, passwords, or private URLs.
- No personal details: names, email addresses, account IDs, or paths like
  `/Users/<name>`; use `~` or `$HOME`.
- No project-specific content: repo or org names, issue numbers, internal
  tooling, or rules that only make sense in one project. Those belong in that
  project's own docs.

Check every new or edited skill against this list before committing.
